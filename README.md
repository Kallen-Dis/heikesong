# 语枢 Semantica

**让 AI 取得带口径、执行证据和使用条件的数据。**

面向赛题二「AI 使用的大数据平台」，语枢在现有数仓之上提供语义执行网关：先确认问题的含义，再执行可核对的计算，并说明结果能支持哪些结论。

一个物流例子解释我们要解决的问题：承运商 A 的总体超时率为 **2.8%**，B 为 **8.2%**；拆到同一区域后，A 却都更高。若明确采用相同的 50/50 区域构成，A 为 **6%**，B 为 **5%**。这些数字都算对了，直接据此更换承运商却仍缺少效果证据。
