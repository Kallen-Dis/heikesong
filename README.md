# 语枢 Semantica

**让 AI 在证据不足时，知道下一步该做什么。**

赛题二 A · AI 使用的大数据平台

语枢在现有数据仓库之上，提供带业务口径、执行证据与使用条件的数据能力。当查询结果不满足任务要求时，平台返回具体冲突或缺口，AI 据此选择补证工具，继续推进任务。口径、覆盖范围和授权始终由平台检查。

## 一项任务，看到完整过程

“按已妥投口径，在相同区域构成下比较两家承运商。”

1. **发现冲突**：两份产品返回的分母不同，平台指出哪一个字段不满足要求。
2. **选择修复**：AI 请求同口径证据，查询引擎执行，结果进入证据台账。
3. **形成比较**：服务端根据有效证据生成描述性结论。
4. **改变条件**：调整区域权重，复用计数重新计算；撤销数据来源或更新数据，旧结论随之失效。

## 为什么需要这样的数据平台

同一个“超时率”，可能采用已妥投或全部运单作为分母；同一个总体排名，也可能混入两家不同的业务构成。语枢把这些隐含条件变成可检查的接口，让 AI 获得数字时，也能知道数字支持什么结论、还缺什么证据。

本体与指标目录统一业务含义，执行引擎负责计算，任务反馈引导后续取证。已有数仓继续承担存储与查询。
