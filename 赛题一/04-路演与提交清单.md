## 2. 初赛提交前检查

- [ ] 已确认本队参赛与选题信息，并核对平台提交位置。
- [ ] 运营方案包含用户、目标、卖点、内容、渠道、转化路径、排期、预算和风险。
- [ ] 用户判断有真实访谈或体验证据，推断和事实分别标注。
- [ ] 提交至少一项实际发生、可核验的执行材料，写清日期与范围。
- [ ] 目标值与实绩分开；未知数据保留为空，不使用合成数据冒充增长成绩。
- [ ] 官方激活口径、归因、统计期与去重单位已确认，或明确披露未确认项；制品浏览、点赞和分享按来源口径单列。
- [ ] 已有账号、团队自用账号与真实新增用户分开处理。
- [ ] 演示能展示任务、产出、访问方式与限制；链接和目标访问权限可用。
- [ ] 材料中的出处、作者授权、图片与数据使用范围已核对。
- [ ] 视频时长不超过 5 分钟，演示材料与文中结果一致。
- [ ] 最终检查由另一位队员完成；内部目标 10 月 14 日 20:00 完成封包。

以上未打勾项均为待办，不代表本次自动创建文档已替团队完成。

## 3. 5 分钟讲述结构

现阶段按「初稿说明版」讲，使用将来时和规划目标。发生真实执行后，再把指定段落替换为有来源的结果。不要直接把计划数字改写为成功成绩。

| 时段 | 画面 | 初稿说明的核心句 |
|---|---|---|
| 0:00-0:35 | 一句主张与一件小作品示意 | 我们想帮助 AI / 数据学习者把一次尝试变成一件可展示成果；这个需求判断还会通过访谈验证。 |
| 0:35-1:15 | 目标用户与待访谈问题 | 首先面向华师大 AI / 数据学习者，聚焦选题、交付标准和展示路径三个可能的障碍。 |
| 1:15-2:15 | 用户路径、三个小任务 | 专属入口、参考任务、制作、成果回传、同伴反馈和一周后改进形成完整路径。 |
| 2:15-3:15 | 演示步骤或真实试运行记录 | 计划用短工作坊带新人走通步骤，并记录实际卡点；示例数据明确为合成，不是平台增长结果。 |
| 3:15-4:20 | 指标口径与目标表 | 官方归因增长与团队价值行为分别统计；目标包含 60 个新增注册与 10 位首件合格制品用户，均待实测。 |
| 4:20-5:00 | 排期、资源依赖与改进规则 | 先验证需求和上手，再扩大触达；实测取得后台数据后，按成果与复访决定是否继续扩展。 |

团队首次价值：[V]；首件合格制品用户：[Q]。
选定制品的浏览/点赞/分享：[数值、各自单位与后台口径]。
互动数据缺失项：[明确填写]；来源证据：[编号]。
当期共观察到 [成熟人数] 位完成D7窗口，

尚在观察中的用户：[人数]。

目标未达项：[真实差距]。

只有符合第三份文件定义的数据才能填入相应位置。分渠道无法统计、样本量小或行为仅有自报时，应说明这些限制。

## 5. 建议准备的五页内容

1. **问题与用户**：一个真实用户故事、一个反例、选择主目标的依据。
2. **活动机制**：用户从入口到首件成果的路径、三个小任务与帮助方式。
3. **执行证据**：已发生的发布/工作坊/修改记录；正在计划的部分单独标识。
4. **增长与使用**：目标对照实际，官方归因、制品质量与 D7 成熟窗口。
5. **复盘与下一步**：失败点、投入、修正动作及值得继续的机制。

首轮修改期间优先维护 Markdown 文档；内容稳定后再转为演示文稿或 PDF，避免多份文件的目标与实绩不同步。

## 6. 与总决赛的衔接

工作区赛事方案写的是每队「8 分钟路演 + 4 分钟问答」。建议整个团队预留约 3 分钟讲运营，约 4 分钟讲赛题二，约 1 分钟讲两者关联与下一步；最终安排以组委会通知为准。

运营部分不要讲完所有功能，优先说明：谁愿意使用、哪种体验带来实际成果、平台怎样认定增长、哪条假设被证据推翻。赛题二的技术能力与平台增长结果各有自己的证据。

## 7. 评委可能追问的问题

| 问题 | 回答要点 |
|---|---|
| 为什么选择作品共创？ | 先说明用户访谈，再展示体验行为；需求未验证时直说是试验方向 |
| 新增用户是不是本来就会注册？ | 按官方首次入口规则报告可归因人数；没有随机对照，不能声称净增量因果效果 |
| 如何防止只注册不用？ | 对照官方激活、首次价值、合格制品和 D7 窗口，不用单一注册数代替 |
| 你们的激活为什么和平台不同？ | 平台 A 和团队 V 分别定义与报告，不把自定义指标包装成官方激活 |
| 两个渠道哪个有效？ | 只有获准的分渠道数据才能精确比较，否则用辅助观察并说明不可识别性 |
| 能否扩大到其他高校？ | 先复用已验证任务与说明，在相近社群试小规模扩展；预算与支持另行确认 |
| 这份初稿目前做到了哪一步？ | 完成策划、素材和记录模板；真实访谈、发布、增长实绩与演示录制仍待完成 |
